# Discover — Responsive Web Experience

A responsive and accessible web experience built as part of my internship project.

## 🌐 Live Demo

https://zari404.github.io/decodelabs-project-1/

## 📌 Project Overview

Discover is a responsive web experience designed with a mobile-first approach.

The project focuses on creating a clean, accessible and responsive interface using core web technologies.

## ✨ Features

- Responsive mobile-first design
- Semantic HTML structure
- Responsive navigation
- Interactive mobile menu
- Smooth navigation between sections
- Interactive hover effects
- Accessible navigation controls
- Responsive content card layout
- GitHub Pages deployment

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
- GitHub Pages

## 📱 Responsive Design

The interface adapts to different screen sizes:

- Mobile
- Tablet
- Desktop

CSS Grid is used for the main card layout, while Flexbox is used for navigation and smaller interface components.
